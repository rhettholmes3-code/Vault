# 统计分析模块设计稿 (Statistics Module Design)

> 对应 UX 文档 3.2 章节：月度统计 & 年度统计
> **最后更新**: 2026-01-11 (基于 Prototype 实现同步)

---

## 1. 核心交互架构

`Overview.html` 采用单页应用 (SPA) 模式，顶部提供三种视图状态切换：

| Tab | 模式 | 内容 |
|-----|------|------|
| **本月** | 账本模式 | 资产卡片 + 交易流水列表 |
| **月度** | 统计模式 | 最近12个月趋势/结构图表 + 分类排行 |
| **年度** | 统计模式 | 最近5年趋势/结构图表 + 分类排行 |

### 时间导航
- **位置**: 顶部栏右侧 (统计模式下显示)
- **格式**: `< 2026.01 >` (月度) / `< 2026 >` (年度)
- **功能**: 左右切换周期, "回到今天" 按钮

---

## 2. 汇总卡片组 (Summary Cards)

横向滚动的玻璃态卡片，展示核心指标：

| 卡片 | 数据 | 样式 |
|------|------|------|
| **结余** | `¥X,XXX` | 蓝色主色 |
| **总收入** | `¥X,XXX` + 涨跌幅 | 绿色 + `↑ 12%` 徽章 |
| **总支出** | `¥X,XXX` + 涨跌幅 | 红色 + `↓ 5%` 徽章 |
| **日均支出** | `¥XXX.XX` | 橙色 |
| **预算剩余** | 环形进度条 `75%` | 动态颜色 (绿/黄/红) |

### 预算进度环逻辑
- `>50%` 剩余: 绿色 (Healthy)
- `20%-50%` 剩余: 黄色 (Warning)
- `<20%` 剩余: 红色 (Critical)

## 3. 核心分析图表 (Core Chart)

### 3.1 双模式切换
- **[趋势]**: 双折线图 (收入 vs 支出) + 预算虚线
- **[结构]**: 堆叠柱状图 (分类占比)

### 3.2 图表细度
| Tab | 横轴 | 数据范围 |
|-----|------|----------|
| 月度 | 月 (1月-12月) | 最近12个月 (滚动窗口) |
| 年度 | 年 (2022-2026) | 最近5年 (滚动窗口) |

### 3.3 可视化元素
- **收入线**: 绿色 (#22c55e), 细线
- **支出线**: 蓝色 (#3b82f6), 粗线, 填充渐变
- **预算线**: 灰色虚线 (#94a3b8)
- **图例**: 底部圆点图例 (收入 / 支出 / 预算)

### 3.4 交互功能
| 交互 | 效果 |
|------|------|
| 点击数据点 | 高亮选中点, 下方列表筛选至该月/年 |
| 再次点击 | 取消选中, 恢复默认视图 |
| 左右滑动 | 切换上一/下一周期 |

## 4. 分类排行列表 (Ranking List)

### 4.1 切换控件
- `[支出]` / `[收入]` Segmented Control

### 4.2 布局
```
┌─────────────────────────────────┐
│  🍔 餐饮美食                     │
│  ══════════════════ 50%  ¥5,000 │
│                                 │
│  > 展开查看明细                  │
└─────────────────────────────────┘
```

### 4.3 穿透交互 (Drill-down)
- 点击分类卡片 → 手风琴展开该分类下的交易明细
- 明细项显示: 日期 | 备注 | 金额

---

## 5. 动效与体验 (Motion & UX)

### 5.1 入场动效
| 元素 | 动画 |
|------|------|
| 汇总卡片 | Staggered Fade-in (75ms 间隔) |
| 图表 | Y轴生长动画 (2s, easeOutQuart) |

### 5.2 骨架屏 (Skeleton)
- 数据加载时显示闪烁占位符 (`.skeleton` 类)

### 5.3 触感反馈 (Tactile)
- 选中点: 放大 + 实心填充
- 非选中点: 变淡 (opacity 0.3)
