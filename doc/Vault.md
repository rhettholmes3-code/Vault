# Vault - 个人记账应用

> 🔒 **核心价值：隐私优先** — 完全离线运行，无需网络，数据存储在本地。

---

## 项目概述

Vault 是一款专为个人用户设计的离线记账应用。所有数据存储在设备本地，确保用户的财务隐私不被泄露。

## 技术栈

| 层级 | 技术 |
|------|------|
| **前端框架** | 纯 HTML + Tailwind CSS |
| **图表库** | Chart.js (CDN) |
| **数据存储** | LocalStorage |
| **图标** | Material Symbols + Remix Icon |

## 核心功能

- ✅ 快速记账 (支出/收入)
- ✅ 分类管理 (支持自定义图标)
- ✅ 统计分析 (月度/年度趋势图)
- ✅ 预算追踪 (环形进度条)
- ✅ 深色模式
