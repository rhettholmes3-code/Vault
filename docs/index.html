Vault Privacy Policy / 隐私政策

Last updated / 更新日期: 2026-06-03

🔒 Privacy Commitment:
Vault is a privacy-first, completely offline personal expense tracker. We DO NOT collect, store, or transmit any of your personal financial data. All data is saved locally on your device.
🔒 隐私核心承诺：
Vault 是一款隐私优先、完全离线的个人财务记账应用。我们不收集、不存储、不传输您的任何个人财务数据。所有数据均保存在您设备的本地 SQLite 数据库中。

1. Data Collection & Use

The app runs entirely offline and does not require account registration:

  • Financial Records: Every expense, income, budget, and category you record is saved only on your personal device.
  • Network Permission: The app does not request internet access permissions, ensuring your financial data is never sent to the cloud.

2. Data Storage & Security

All data is stored within the app sandboxed SQLite database. If you uninstall the app, your data will be permanently deleted. You can use the "Export CSV" feature in settings to backup your data manually.

3. Changes to This Policy

We may update our Privacy Policy from time to time. Any changes will be posted on this page.

4. Contact Us

If you have any questions, please open an issue in our GitHub repository.

1. 数据收集与使用

本应用完全离线运行，无需注册任何账号：

  • 财务记录：您记录的每一笔支出、收入、预算和类别均只保存在您本人的设备上。
  • 网络权限：应用不要求网络连接权限，您的账单数据绝无泄漏到云端的可能。

2. 数据存储与安全

所有数据由 SQLite 驱动存储于应用沙盒中。如果您卸载本应用，保存在本设备上的账单数据将被永久清除。建议您使用应用内提供的“CSV 导出”功能定期手动备份数据。

3. 隐私政策的变更

我们可能会不时更新本隐私政策。任何更改都将在此页面公布。

4. 联系我们

如果您对本隐私政策有任何疑问，请通过 GitHub 仓库向我们提交 Issue。
